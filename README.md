# The Whetstone — marketing site

This is the public marketing site for [Devil's Advocate](https://github.com/Daniell-44/The_Whetstone_Project), the Chrome extension surface of The Whetstone. Live at **https://devils-advocate-site.pages.dev**.

Three pages: home (what the tool is + install CTA), how it works (Toulmin frame explained), and privacy policy (rendered from the extension repo at build time).

Built with **Astro 6** and **Tailwind CSS v4**. Static output, deployed to Cloudflare Pages.

---

## Running locally

```bash
pnpm install
pnpm dev        # dev server at localhost:4321
pnpm build      # production build → ./dist
pnpm preview    # preview the production build locally
```

The privacy page reads `../extension/PRIVACY.md` at build time via `node:fs`. The extension repo must be checked out as a sibling directory (`../extension/`) for builds to succeed.

---

## Deploying

```bash
pnpm build
npx wrangler pages deploy dist --project-name devils-advocate-site --branch main
```

Wrangler requires a Cloudflare account and will open a browser login on first run.

## Structure

```

  layouts/Base.astro    Shared HTML shell — OG tags, footer, nav
  pages/
    index.astro         Home — The Whetstone brand mark + Devil's Advocate CTA
    how-it-works.astro  Toulmin model explained in plain English
    privacy.astro       Reads ../extension/PRIVACY.md at build time
  styles/global.css     Tailwind v4 import + theme (system font stacks)
public/
  favicon.svg
  og-image.png          1200×630 OG image (generated by scripts/gen-og.mjs)
  robots.txt
scripts/
  gen-og.mjs            Generates og-image.png using Sharp
```
